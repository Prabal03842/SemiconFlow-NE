# SemiconFlow-NE

Working Streamlit prototype for a NESFIC 2026 Stream 2 / Track A open-innovation concept.

## Purpose
SemiconFlow-NE demonstrates technology-gated semiconductor supply-chain resilience, critical-material planning, disruption simulation, strategic-buffer design, and localization screening for Assam's emerging semiconductor ecosystem.

## Evidence boundary
All operational data and performance results in this repository are synthetic and industry-inspired. They are not Tata Electronics, Government of Assam, supplier, or any other company's confidential data or actual performance.

## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy on Streamlit Community Cloud
Create a GitHub repository and upload all files/folders at the repository root. Deploy with:
- Branch: `main`
- Main file: `streamlit_app.py`
